The generated Frontier portrait set in `frontier/client/portraits/` contains the two stewards, their Duskwear outfits, Commander Iona and the three Frontier Relay specialists Nim, Varren and Mira Vesper. The Relay portraits use a shared Emberwell backdrop. The portrait files are distributed for use in the game under these asset terms. The Phaser maps use source-code-rendered pixel art. The earlier wallet prototype uses a landscape drawn in CSS. The original 2024 image files are absent from this repository.
